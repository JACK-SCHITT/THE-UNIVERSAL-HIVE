1. Local mode

The file is the whole app. There is no Node process, no Express app, no account, and no database. The status line stays Local Mode · Ready because nothing is waiting on a server.

2. The three checks

Validate Configuration passes only when a base is selected, a role is selected, and at least one package is selected. Anything missing is named in the deployment plan.

3. A plan is text

Export Plan downloads a text file and tries to copy it. If the copy does not stick, long-press inside the plan, choose Select All, then Copy. The text is a checklist you can keep. It is not a script, and this page will not run it.

4. Identity

Generate identity makes a callsign from random bytes in the browser. Regenerating replaces it. Clearing removes it. Validation does not require it.

5. What security review is

It repeats the same local checks and states, in writing, that no scan ran. If a field is missing, it says which one. It never invents open ports or a machine report.

Save the file

        
The name must end in .html, for example hive-os.html or index.html. If it ends in .txt, Safari shows the code instead of the app. Download the file. Do not paste it into Notes, Mail, or Messages — those apps often add .txt or strip the script.

      

      

        
Open it on a Mac

        
Control-click hive-os.html, then choose Open With and Safari. Do not open it in TextEdit. The status line should read Local Mode · Ready. If you only see the source code, the file name is wrong or the editor saved a text copy.

      

      

        
Open it on an iPhone or iPad

        
Open this address in Safari: https://krackerjack-hive-os.vercel.app/ The buttons run there. A Files preview is not Safari. Only if that address is down: save hive-os.html in Files, tap it, tap Share, then choose Safari if it is listed.

      

      

        
Open this page

        
The live address is https://krackerjack-hive-os.vercel.app/ Open that in Safari. GitHub Pages is not on, so jack-schitt.github.io/hive-os is not the app. No build step, no account, and no secret. The page never leaves the browser.

      

      

        
Use the plan

        
Pick a base, a role, and at least one package. Validate Configuration writes pass or the missing items in the deployment plan. Export Plan downloads krackerjack-hive-plan.txt and tries to copy the same text. The plan box is not selected for you. If the copy does not stick, long-press inside the plan, choose Select All, then Copy.
