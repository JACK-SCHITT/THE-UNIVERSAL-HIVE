# Agents on the board

Route returns a name. It does not launch the agent.

| Task | Agent | State |
|---|---|---|
| recovery / index | HunterPrime | demo label |
| forensics / scan | SCRAP | demo label |
| build / construct | FoundryHive | demo label |
| general | KRACKERJACK | demo label |
| empty task | DynamicRouter | demo label |
| radio / coax / relay / ptt | RADIO | demo stack, fail-safe receive |

JACKSCHITT, PULSE, DRAGONFLY, Bonsai 2, and ScamShield are demo shells.
They are not hive providers. They do not call out.
