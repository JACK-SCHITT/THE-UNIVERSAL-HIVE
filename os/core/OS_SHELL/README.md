# HIVE AI OS Desktop Shell

## Law

**The apps are the OS.**  
You built the operating system in pieces (OpenClaw, AssimilateOrDie, KRACKERJACK AI, GROKSCHITT, OnSpace, Movie Maker, GENESIS).  
This shell **reunites every look, screen, button, and option** as one desktop.

## Launch

```
C:\Users\ARCHITECT\THE_HIVE\OS_SHELL\Start-HiveDesktop.cmd
```

Desktop shortcut: **HIVE AI OS DESKTOP**

## What you get

| Layer | Source app | OS surface |
|--------|------------|------------|
| Hunter / Terminal / ZORG / Vault | OpenClaw Prime | HUNTER + TERMINAL |
| Build / Progress / Hive | AssimilateOrDie | FOUNDRY |
| Chat / DNA / Analytics / Config | KRACKERJACK AI | CHAT DNA ANALYTICS CONFIG |
| Web UI | GROKSCHITT | DNA web |
| Deploy | OnSpace | ANALYTICS / deploy |
| Stories | Movie Maker | MEDIA |
| Kernel UI | GENESIS cockpit | COCKPIT |
| Local brain | LOCAL_OS firstboot | Local Ollama AI |

Bottom dock = your original OS bar:  
**FOUNDRY · HUNTER · CHAT · DNA · ANALYTICS · SEARCH · TERMINAL · CONFIG · MEDIA · COCKPIT**

## Files

- `hive-desktop.html` — full OS shell UI  
- `modules.json` — registry of every app module + screens  
- `Start-HiveDesktop.cmd` — launcher
