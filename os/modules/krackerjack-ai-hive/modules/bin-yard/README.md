# BIN YARD

Hive module for orphan wireless keyboards and mice sitting without a USB receiver.

## Why this exists

A trailer of 2.4 GHz office gear is not one problem. It is several radios dumped in the same bin.

- Bluetooth units pair in the OS. No stick.
- Logitech Unifying / Bolt take a genuine family receiver and official pairing software.
- Microsoft 2.4 GHz takes the official stick sold for that exact model.
- Generic no-name 2.4 GHz is factory-married to one nano. Empty slot = parts.
- Infrared is light, not radio.
- Wired USB mixed into wireless bins is easy money.

## Law

1. Anything in, one path out. No mystery pile.
2. The McGillicuddy is hardware. The hive does not impersonate receivers.
3. Hassle once, reuse forever. First sighting of a mark gets written down.
4. Do not list a dead generic 2.4 unit as working wireless.

## What this module will not ship

No RF sniffer. No fake dongle. No pairing-key clone off the air. Those are keylogger / injection kits, not a salvage desk.
